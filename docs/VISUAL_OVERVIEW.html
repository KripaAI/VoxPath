3 Live Voice Flow (voice-to-voice)

Continuous PCM streaming with server-side VAD, tool calls mid-turn, and half-duplex playback.

sequenceDiagram
    autonumber
    participant U as User
    participant B as Browser (AudioWorklet)
    participant WS as /ws/voice
    participant G as Gemini Live (Vertex)
    participant MCP as MCP tool
    U->>B: speaks
    B->>WS: 16kHz PCM16 (binary)
    WS->>G: forward audio (Blob)
    Note over G: server-side VAD detects end of turn
    alt model needs live data
        G->>WS: tool_call
        WS->>MCP: call_tool(name, args)
        MCP-->>WS: result (dict)
        WS->>G: FunctionResponse
    end
    G->>WS: 24kHz PCM16 answer + transcripts
    WS->>B: audio frames + JSON control
    B->>U: plays answer (jitter-buffered)
    Note over B: mic muted while speaking; barge-in flushes playback

4 Text Chat Flow

LangGraph ReAct agent decides a tool call, answers only from returned data.

sequenceDiagram
    autonumber
    participant U as User
    participant UI as ChatInterface
    participant API as POST /chat
    participant AG as LangGraph agent
    participant LLM as ChatVertexAI (Gemini)
    participant MCP as MCP tool
    U->>UI: types message
    UI->>API: { message }
    API->>AG: agent_chat(message)
    AG->>LLM: reason about intent
    LLM-->>AG: decide tool call
    AG->>MCP: call tool (news / market / railway)
    MCP-->>AG: live data
    AG->>LLM: compose answer from data
    LLM-->>AG: final text
    AG-->>API: reply text
    API-->>UI: { text }
    UI-->>U: renders answer
    Note over API: quota error gives friendly fallback (not 500)

5 Image → Video Flow

Optional text→image (Nano Banana), then a long-running Veo job, polled to completion.

sequenceDiagram
    autonumber
    participant U as User
    participant VS as VideoStudio
    participant IMG as POST /image/generate
    participant NB as Nano Banana
    participant VG as POST /video/generate
    participant JOB as async job
    participant VEO as Veo (Vertex)
    opt generate source image
        U->>VS: image prompt
        VS->>IMG: { prompt }
        IMG->>NB: text to image
        NB-->>IMG: PNG bytes
        IMG-->>VS: image (becomes source)
    end
    U->>VS: motion prompt + aspect ratio
    VS->>VG: multipart (image, prompt, ratio)
    VG->>JOB: start background task
    VG-->>VS: { job_id, running }
    JOB->>VEO: start long-running op
    loop poll (10s server / 5s client)
        VEO-->>JOB: status
        VS->>VG: GET /video/status/{id}
    end
    JOB->>JOB: write generated_videos/{id}.mp4
    VS->>VG: GET /video/result/{id}
    VG-->>VS: MP4 to play + download
